Parsons Problems Interoperability

Working Group

Rationale

The goal is to set standards for Parsons Problems that support reusable exercise descriptions and consistent generation of output event traces.

Reusable Exercise Descriptions

Cliff Shaffer has been working on a PEML-based file format that aims to capture most Parsons problem variations currently in use.

  • See the draft problem definition specification.
  • See the examples repository.
  • See descriptions of the examples.

Output Event Traces

The group also supports consistent generation of output event traces, probably in a file format based on ProgSnap.
